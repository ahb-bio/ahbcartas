# 🔮 Desvendando Oráculos - Baralho Cigano & Tarot

> Plataforma web interativa e educacional para estudo, consulta e interpretação do **Baralho Cigano (Petit Lenormand)** e do **Tarot (Arcanos Maiores e Menores)**.

---

## 🌟 Sobre o Projeto

**Desvendando Oráculos** é uma aplicação web moderna projetada para estudantes, praticantes e entusiastas das artes oraculares. Desenvolvida sob a orientação e curadoria do instrutor **Antonio Bezerra**, a plataforma combina o conhecimento tradicional dos oráculos com uma interface digital intuitiva, responsiva e de alta resolução.

---

## ✨ Principais Funcionalidades

### 🃏 Galeria do Baralho Cigano (Petit Lenormand)
- **36 Cartas Sagradas**: Catálogo completo das 36 cartas (de *O Cavaleiro* à *A Cruz*).
- **Detalhamento Completo**:
  - Palavras-chave e polaridade (positiva, negativa, neutra).
  - Significados práticos para Vida Geral, Amor e Carreira.
  - Conselhos reflexivos e temporização (estimativa de tempo).
  - Correspondência com a cartomancia tradicional (naipes e figuras do baralho comum).
- **Visualização Ampliada**: Modal interativo com a imagem de cada carta em alta definição.

### 🎴 Galeria do Tarot (Arcanos Maiores e Menores)
- **Arcanos Maiores**: As 22 cartas arquetípicas (de *0 - O Louco* a *XXI - O Mundo*).
- **Arcanos Menores**: Todas as cartas dos 4 naipes (Paus, Copas, Espadas e Ouros).
- **Simbolismo Elemental**: Associação com os elementos (Fogo, Água, Ar e Terra), interpretações diretas/revertidas e orientações reflexivas.

### 📐 Métodos de Tiragem & Esquemas Práticos
Diagramas ilustrados e guias passo a passo para execução de tiragens oraculares:
- **Método das 3 Cartas**: Linha do Tempo (Passado, Presente e Futuro).
- **Templo de Afrodite**: Análise afetiva e relacional em formato H (7 cartas).
- **Tiragem das 9 Cartas**: Grade 3x3 para visão panorâmica e conexões temporais.
- **Método Situações**: Disposição em Cruz (4 cartas).
- **Tiragem Mensal**: Previsões e tendências para o período.
- **Polaridade & Sim ou Não**: Respostas diretas e análise de dinâmicas energéticas.

### 🎨 Design Místico & Alta Performance
- Interface escura e imersiva (`#0d0b14`) com detalhes dourados elegantes (`#c5a059`).
- Tipografia refinada utilizando as fontes **Cinzel** e **Plus Jakarta Sans**.
- Layout 100% responsivo para celulares, tablets e computadores.

## 🚀 Como Executar Localmente

### Pré-requisitos
Ter o **Node.js** (v18 ou superior) instalado em seu computador.

### Passo a passo

1. **Clonar ou baixar o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/desvendando-oraculos.git
   cd desvendando-oraculos
   ```

2. **Instalar as dependências:**
   ```bash
   npm install
   ```

3. **Iniciar o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acessar no navegador:**
   Abra `http://localhost:3000` no seu navegador.

---

## 🌐 Deploy no GitHub Pages (Upload pelo Navegador)

Caso deseje enviar o site diretamente pelo navegador sem usar o Git CLI:

1. Abra a pasta [`site_para_github_pages`](./site_para_github_pages).
2. No seu repositório no GitHub, clique em **Add file** -> **Upload files**.
3. Selecione e arraste **todos os arquivos soltos** contidos em `site_para_github_pages`.
4. Clique em **Commit changes**.
5. No GitHub, acesse **Settings** -> **Pages**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/ (root)`. Clique em **Save**.
